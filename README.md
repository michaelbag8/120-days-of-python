# 🐍 120 Days of Python Challenge

> **"Consistency beats intensity. One day at a time, one line of code at a time."**

## Challenge Description

The **120 Days of Python Challenge** is a commitment to becoming a confident Python developer through deliberate practice, project-based learning, and consistent coding.

This challenge is not about finishing tutorials or collecting certificates. It is about developing the ability to think like a programmer, solve problems independently, read and understand code, write clean and maintainable programs, and build real-world applications.

The roadmap consists of **46 structured lessons** covering Python fundamentals, data structures, object-oriented programming, algorithms, advanced Python features, testing, and concurrency. Every lesson will be reinforced with practice problems, debugging exercises, code reading, and projects.

At the end of 120 days, the goal is to have both a strong understanding of Python and a portfolio that demonstrates practical software development skills.

By the end of this challenge, I will be able to:

# Non-Negotiable Rules

## 1. Code Every Day

No zero days.

Even if I only have 15–30 minutes, I must write code.

---

## 2. Type Every Line Yourself

Never copy and paste tutorial code.

Typing builds muscle memory.

---

## 3. Understand Before Moving On

Do not move to the next lesson until I understand the current one.

---

## 4. Build Before Watching Solutions

Attempt every exercise and project before asking for help.

---

## 5. Embrace Bugs

Every error is an opportunity to learn.

Read the error message first before searching online or asking for help.

---

## 6. Use Version Control

Commit code regularly with meaningful commit messages.

---

## 7. Write Clean Code

Prioritize readability over cleverness.

Follow Python best practices and PEP 8.

---

## 8. Review Previous Lessons

Spend time revisiting earlier concepts to strengthen retention.

---

## 9. Finish What You Start

Complete every lesson, exercise, and project before moving on.

---

## 10. Build a Portfolio

Projects are more valuable than certificates.

Every completed project should be polished and added to GitHub.

---

## 11. Learn Actively

Don't just watch or read.

Pause often, predict outputs, experiment with the code, and ask "why?" as much as "how?".

---

## 12. Stay Consistent

Progress is measured by showing up every day, not by perfection.

---
